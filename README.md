Overview

OBSIDIAN XII is a premium, design-first flagship device concept presented through a high-end, minimalistic web experience. This project showcases a luxury product landing page inspired by precision engineering, Swiss craftsmanship, and modern digital aesthetics.

The website emphasizes:

Ultra-clean typography
Cinematic layout and storytelling
Product-focused UI/UX
High-end branding and exclusivity
✦ Product Concept

The Obsidian XII represents a phone reduced to its purest form.

6.7″ LTPO Display (1Hz–144Hz)
Triple 200MP Camera System
Grade-5 Titanium Body
OBX-1 3nm Custom Chip
5400mAh Battery · 120W Charging
7.2mm Thin · 198g Weight

Built with precision. Owned by those who choose quietly.
